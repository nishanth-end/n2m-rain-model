Generative Synthetic Simulation Mechanics

Generated by model/make_mock_dataset.py to unblock full-stack engineering and evaluation loops prior to Member 1's real satellite/radar dataset handoff.

Spatial Matrix: 600 synthetic cells spanning Bengaluru latitude (12.85° to 13.15°) and longitude (77.45° to 77.80°). Realistic topography includes elevation (~900m DEM), slope, Topographic Wetness Index (TWI), HAND, impervious fraction (10% to 95%), and proximity to stormwater channels.

Generative Logit: Ground-truth binary labels are generated by simulated hydrological dynamics:

z = 0.05 * rain_3d_mm + 0.25 * twi - 0.35 * hand_m - 0.002 * dist_lake_m + 1.5 * imperv_frac - 5.5
P(flood_label = 1) = 1 / (1 + exp(-z))

Zero-Code Real Data Drop-In: Dropping the real flood_dataset.csv into data/ and retraining immediately updates the entire platform with zero code changes.
