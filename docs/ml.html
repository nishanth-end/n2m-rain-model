Understanding These Metrics

PR-AUC vs Chance: In low-prevalence flood events, ROC-AUC gives an overly optimistic assessment due to the abundance of true negatives. PR-AUC measures precision across all recall levels; true skill is reflected by lift over the horizontal chance line.

CSI (Critical Success Index): Calculated as TP / (TP + FP + FN). Evaluates detection efficiency while penalizing both false alarms and missed warnings.

Known Limitations & Disclosures

1. Synthetic Baseline Dataset
Trained on generated mock data. Predictions illustrate architecture and are not real forecasts.
2. Optimistic Threshold Tuning
The best-CSI decision threshold was determined across pooled evaluation sets and requires held-out validation.
3. Uncalibrated Hazard Index
Due to class weighting and confidence scaling, scores reflect relative flood hazard, not calibrated probabilities.
4. Excluded Hydrological Columns
hand_m and dist_lake_m were withheld from this training configuration pending Member 1 pipeline completion.
