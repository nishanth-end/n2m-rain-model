How to Read These Metrics

PR-AUC vs Chance: Because floods are rare (low base rate), standard ROC-AUC gives an unrealistically flattering score. PR-AUC measures precision across recall levels; a useful model significantly outperforms the random chance rate (the horizontal prevalence baseline).

CSI (Critical Success Index): Defined as TP / (TP + FP + FN). Unlike accuracy, CSI penalizes false alarms and misses equally while giving zero credit for correctly predicting dry days.

Known Limitations & Disclosures

1. Synthetic Demonstration Dataset
Trained on generated mock data with simulated relationships. Scores do not represent real operational forecasts.
2. Optimistic Threshold Selection
The best-CSI decision threshold was evaluated on the pooled predictions and requires confirmation on independent future storm events.
3. Uncalibrated Relative Risk Score
Due to class balancing (scale_pos_weight) and confidence sample weighting, scores reflect relative flood propensity, not true probabilities.
4. Excluded Hydrological Features
hand_m and dist_lake_m were not utilized by this active model run and await the full data pipeline handoff.
